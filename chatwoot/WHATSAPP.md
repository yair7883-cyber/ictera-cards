# חיבור וואטסאפ ל-Chatwoot ושליחת קמפיינים

החיבור הוא דרך ה-API הרשמי של Meta ‏(WhatsApp Cloud API). לפני שמתחילים:
Chatwoot כבר צריך לרוץ על השרת עם כתובת HTTPS (ראו README.md), כי Meta שולחת
אליו את ההודעות הנכנסות.

## מה צריך להכין

- **מספר טלפון ייעודי** שלא מחובר כרגע לאפליקציית וואטסאפ (סים חדש או מספר וירטואלי
  שמקבל SMS או שיחה). אם רוצים להשתמש במספר קיים — קודם מוחקים ממנו את החשבון באפליקציה.
- **חשבון פייסבוק** של בעל העסק.
- **אמצעי תשלום** — Meta גובה על כל הודעה שיווקית (תשובות ללקוח שפנה אליך בתוך 24 שעות חינמיות).

## שלב 1 — חשבון עסקי ב-Meta

1. נכנסים ל-business.facebook.com ויוצרים Business portfolio (שם העסק, שם, מייל).
2. מומלץ לאמת את העסק (Security Center → Business verification). בלי אימות אפשר
   לשלוח הודעות יזומות ל-250 אנשים ביום; אחרי אימות המכסה עולה בהדרגה.

## שלב 2 — אפליקציה ומספר

1. developers.facebook.com → **My Apps → Create App** → סוג **Business** → מקשרים ל-portfolio.
2. בתוך האפליקציה: **Add product → WhatsApp → Set up**.
3. **WhatsApp → API Setup → Add phone number** → מזינים את שם העסק והמספר ומאמתים בקוד.
4. באותו מסך מעתיקים שני מספרים:
   - **Phone number ID**
   - **WhatsApp Business Account ID**

## שלב 3 — טוקן קבוע

הטוקן שמופיע ב-API Setup פג אחרי 24 שעות, לכן יוצרים טוקן קבוע:

1. business.facebook.com → **Settings → Users → System users → Add** → תפקיד **Admin**.
2. **Assign assets**: האפליקציה (Full control) וחשבון הוואטסאפ (Full control).
3. **Generate new token** → בוחרים את האפליקציה → תוקף **Never** → הרשאות
   `whatsapp_business_messaging` ו-`whatsapp_business_management`.
4. מעתיקים את הטוקן ושומרים אותו במקום בטוח (הוא מוצג פעם אחת).

## שלב 4 — חיבור ב-Chatwoot

1. Chatwoot → **הגדרות → תיבות דואר נכנס → הוספת תיבה → WhatsApp**.
2. ספק API: **WhatsApp Cloud**.
3. ממלאים: שם, מספר הטלפון בפורמט בינלאומי (`+9725...`), Phone number ID,
   Business Account ID, ובשדה API key — הטוקן משלב 3.
4. אחרי השמירה, בהגדרות התיבה (לשונית Configuration) מופיעים **Webhook URL** ו-**Verify token**.

## שלב 5 — Webhook (כדי שהודעות נכנסות יגיעו)

1. באפליקציה ב-Meta: **WhatsApp → Configuration → Webhook → Edit**.
2. מדביקים את ה-Webhook URL וה-Verify token מ-Chatwoot → **Verify and save**.
3. ב-**Webhook fields** מסמנים **Subscribe** ליד `messages`.
4. שולחים הודעה מטלפון אחר למספר העסקי — היא אמורה להופיע ב-Chatwoot.

## שלב 6 — תבניות הודעה

הודעה יזומה (למי שלא כתב לך ב-24 השעות האחרונות) חייבת להיות תבנית שאושרה ע"י Meta.

1. business.facebook.com → **WhatsApp Manager → Message templates → Create template**.
2. קטגוריה **Marketing**, שפה **Hebrew**, כותבים את הטקסט (אפשר משתנים כמו `{{1}}` לשם).
3. האישור לוקח בדרך כלל דקות עד כמה שעות.
4. ב-Chatwoot, בהגדרות תיבת הוואטסאפ, מסנכרנים תבניות.

## שלב 7 — שליחת קמפיין

1. **אנשי קשר → ייבוא** — מעלים קובץ CSV עם שם וטלפון (`+972...`).
2. מסמנים את אנשי הקשר שהסכימו לקבל הודעות בתגית (למשל `מאשרים-דיוור`).
3. **קמפיינים → WhatsApp → קמפיין חדש** → בוחרים תיבה, תבנית, ואת התגית כקהל → מועד שליחה.
4. מי שעונה להודעה — השיחה נפתחת ב-Chatwoot ואפשר להמשיך איתו חופשי 24 שעות.

## חשוב — חוק הספאם בישראל

לפי סעיף 30א לחוק התקשורת, אסור לשלוח הודעה פרסומית בלי הסכמה מפורשת מראש.
כל הודעה צריכה להתחיל במילה "פרסומת" ולכלול דרך פשוטה להסיר את עצמך מהרשימה.
הפרה חושפת לתביעה של עד 1,000 ₪ על כל הודעה, בלי צורך להוכיח נזק.
שלחו רק למי שנתן הסכמה, ושמרו תיעוד של ההסכמה.
